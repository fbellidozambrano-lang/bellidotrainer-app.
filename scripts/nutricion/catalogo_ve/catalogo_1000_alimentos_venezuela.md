# Catálogo inicial de 1.000 alimentos para el módulo nutricional

**Alcance:** alimentos básicos, formas de preparación y
alimentos/preparaciones de uso habitual en Venezuela. **Versión:** 1.0
--- catálogo estructural para enriquecimiento y validación.

> **Importante sobre los datos:** este archivo contiene 1.000 registros
> identificables, pero no atribuye valores nutricionales no comprobados.
> Las calorías, macronutrientes, micronutrientes, marcas, GTIN y tamaños
> de porción deben incorporarse desde una fuente documental verificable
> o una etiqueta del producto. Las variantes de preparación no implican
> que exista un análisis de laboratorio específico para cada una.

## Convenciones de calidad

-   `PENDIENTE_FUENTE`: falta asociar una fuente nutricional
    verificable.
-   `PENDIENTE_ANALISIS`: no hay análisis específico para esa
    preparación o variante.
-   `NO_APLICA`: campo que no corresponde al tipo de alimento.
-   No usar valores estimados como si fueran datos analíticos.
-   Mantener separados alimento genérico, receta calculada y producto de
    marca.
-   Para productos envasados, identificar el SKU exacto y transcribir la
    etiqueta; no inferir composición a partir del nombre de la marca.

## Campos recomendados para la base de datos

`id`, `nombre`, `categoria`, `alimento_base`, `forma_preparacion`,
`estado`, `fuente`, `fecha_verificacion`, `energia_kcal_100g`,
`proteina_g_100g`, `carbohidratos_g_100g`, `grasas_g_100g`,
`fibra_g_100g`, `azucares_g_100g`, `grasas_saturadas_g_100g`,
`sodio_mg_100g`, `marca`, `gtin`, `porcion_referencia_g`.
